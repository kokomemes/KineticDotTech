KINETIC — Multi-page Website (static GitHub Pages build)

Open index.html in your browser to preview locally.

Pages:
- index.html — Overview
- workspace.html — Local interactive workflow demo
- workflows.html — Planned workflow concepts
- agents.html — Planned agent roles
- about.html — Project vision

Assets:
- assets/kinetic-background.png — EXACT user-provided background, shared on every page
- assets/styles.css — Site-wide design
- assets/app.js — Interactive local workflow demo
- assets/favicon.svg — Simple browser tab icon

GITHUB PAGES:
1. Create or open your repository.
2. Upload the CONTENTS of this folder (not the folder itself) to the root of your main branch.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Use the URL GitHub provides. Add a custom domain only after configuring its DNS.

IMPORTANT:
This is a static design preview. The Workspace demo uses timed local UI steps and produces a fixed outline. It does NOT run real AI agents, retrieve blockchain data, call APIs, or execute tasks. Future AI integrations require a backend/API credentials, secure secret handling, and usage controls. Do not expose secret API keys in client-side JS.

External font loading uses Google Fonts, with local system fallbacks if unavailable.
